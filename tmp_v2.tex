We organize them along two axes: \emph{where} in the deployment lifecycle they bite (within an environment vs.\ across environments) and \emph{what kind of data} they require (raw measurements vs.\ dense labels).

\noindent\textbf{Three core challenges} motivate our design. We distinguish them by where in the deployment lifecycle the failure occurs:

\begin{description}[leftmargin=1.8cm, style=nextline]
  \item[\textbf{Volatile, Non-Stationary Noise Patterns (within a deployment).}] Real-world UWB measurements exhibit non-stationary noise statistics within a single deployment. From the tag perspective, user-specific placements (e.g., in-hand vs. in-pocket) distort signal behavior, while vehicle-mounted anchors experience strong reflections and blockages from metallic frames. When combined with moving obstacles, these factors create \emph{moment-to-moment} noise drift that causes static thresholding and pre-trained NLOS classifiers to fail.
  %
  \item[\textbf{High Data Acquisition Overhead (labeling cost).}] Supervised deep learning models require vast quantities of precisely labeled data to capture the full spectrum of environmental noise patterns. However, obtaining dense, accurate ground-truth NLOS features and coordinates across diverse physical layouts and dynamic configurations is logistically complex and labor-intensive, creating a severe bottleneck for practical model training.
  %
  \item[\textbf{Limited Cross-Environment Generalization (between deployments).}] Beyond within-deployment noise, UWB models also have to transfer across physically distinct environments---indoor rooms, outdoor parking, garages---each with its own multipath geometry. A model trained on one environment's noise signature can degrade sharply on another, even when the within-deployment noise has been well handled, because the underlying \emph{propagation distribution} has shifted.
\end{description}

\noindent Our framework systematically overcomes these challenges by introducing three core technical components, each addressing a different axis of distribution shift:

\begin{enumerate}
  \item \textbf{End-to-End Localization via Dual-Channel GCN and Multi-Attention (addresses volatile noise):} Our unified end-to-end architecture leverages data redundancy across cooperative sensors by integrating NLOS detection, signal restoration, and coordinate regression into a single network instead of utilizing isolated stages. Formulated as a graph network, it maps three distinct dimensions of dependencies: dynamic weight matrices preserve environment-independent cross-sensor interactions and encode the hidden physical constraints between heterogeneous channels (radial distance vs.\ directional angle), while a multi-head self-attention module extracts global sensor relationships. This structural constraint enables the network to \emph{implicitly} filter moment-to-moment noise and reconstruct clean measurements end-to-end, without relying on a static NLOS classifier.

  \item \textbf{Simulation-to-Reality Meta-Learning via MAML (addresses data overhead):} To circumvent real-world data collection limits, we utilize the Sionna ray-tracing emulation platform to generate high-fidelity, labeled UWB datasets across diverse virtual topologies. We then employ Model-Agnostic Meta-Learning (MAML) to pre-train the network on these varied environmental tasks. This optimization enables the base model to learn highly transferable feature representations, allowing it to adapt to novel, real-world target scenarios using only a few-shot support set of local reference samples---collapsing the labeling cost of dense supervised coverage.

  \item \textbf{FiLM-based Micro/Macro Disentanglement (addresses cross-environment generalization):} Beyond the meta-learned initialization, we introduce a FiLM-conditioned micro-condition representation $c$ that captures the local propagation state (e.g., NLOS severity per anchor) while a gradient-reversal adversary forces $c$ to be uninformative about the macro environment. At test time, the model composes the macro environment (from the meta-learned features) and the micro propagation condition (from $c$) on the fly, so features learned in one environment can re-combine with the new environment's local noise conditions.
\end{enumerate}

\noindent By integrating these three techniques, our model mitigates moment-to-moment noise through in-network restoration, reduces the labeling burden through synthetic meta-pretraining, and achieves environment-agnostic feature transfer through disentangled composition.
